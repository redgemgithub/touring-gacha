# 探索範囲の仕様修正: 「指定距離以内」から「指定距離に近い帯」へ

## 問題（仕様漏れ）

Phase 2完了後、実機で動作確認したところ、探索範囲50kmを指定した際に候補が現在地から32.4km（指定距離よりかなり近い）の場所になることがあった。これは実装のバグではなく、要件定義書・モックアップ・実装のすべてが一貫して「指定距離**以内**」（0〜Xkmの円内）として作られていたことによる。

- docs/requirements.md: 「探索範囲を指定できること／例：半径50km」（「半径」＝中心から縁までの距離、円内検索を意味する）
- docs/mockups/result-collapsed.png: 「探索範囲 50km **圏内**」という表記、候補距離の例が32.4km
- 実装（`src/lib/overpass.ts`の`buildOverpassQuery`）: Overpass QLの`around:{radiusM}`（円内検索）を使用

このアプリの目的は「指定した距離を走るための目的地を探す」ことであり、「指定距離以内のどこか」ではなく「指定距離に近い場所」を探したい、という意図が要件定義の段階で言語化されておらず、確認もされていなかった（仕様漏れ）。実装ミスではない。

## 決定: 「指定距離±マージン」の帯（バンド）で候補を探す

```
マージン = max(指定距離 × 10%, 5km)
帯 = [指定距離 − マージン, 指定距離 + マージン]
```

| 指定距離 | マージン | 帯 |
|---|---|---|
| 10km | 5km（固定下限） | 5〜15km |
| 30km | 5km（固定下限） | 25〜35km |
| 50km | 5km（10%と一致） | 45〜55km |
| 100km | 10km（10%） | 90〜110km |

固定下限（5km）を設ける理由: 10%だけだと10km選択時に帯幅が2km（9〜11km）と極端に狭くなり、候補が見つからない事態が頻発しやすい。固定下限で小さい指定距離側の帯幅を確保しつつ、大きい指定距離側では10%が効いて「指定距離の割に広すぎる帯」にならないようにする。

## 決定: 候補が見つからない場合、範囲を自動的に広げない

帯を狭めるほど「候補が見つからない」ケースは増えるが、これは正しい結果として扱う。見つからなければ「見つからなかった」と正直に伝える（既存UIの「条件に合う目的地が見つかりませんでした」表示をそのまま使う）。自動的に範囲を広げたり、条件を緩めて何かを無理に返したりする実装はしない。

**Why:** 「見つからないなら見つからなかったと言えばよい。無理にひねり出そうとするべきではない」というユーザーの明確な方針。2回連続で見当違いの候補（近すぎる／遠すぎる）を出すことの方が、1回「見つからなかった」と正直に言われることよりも使い勝手を損なうと判断された。

## 決定: 距離は直線距離のまま。ルーティング（道のり距離）は実装しない

現在の距離計算（`haversineDistanceKm`）は緯度経度からの大圏距離（直線距離）であり、実際に走る道のりの距離ではない。帯検索の導入にあたっても、道のり距離への変更は行わない。

**Why:** ルーティングエンジンの導入は実装コスト・運用コスト（無料枠運用方針）に見合わない。またtouring-gachaの役割は「ナビアプリで指定する情報をコピーできるところまで」であり（要件6）、実際の経路計算・道のり距離の保証はナビアプリ側の役割である。アプリの役割を中途半端にまたぐべきではない、というユーザーの明確な方針。

## 影響範囲

- `src/lib/geo.ts`: 帯（マージン）計算関数を追加
- `src/lib/overpass.ts`: `buildOverpassQuery`が指定距離ではなく帯の上限（外側の境界）でOverpassに問い合わせるよう変更
- `src/types.ts`, `src/routes/destinations.ts`: `/process`で帯フィルタ（現在地からの距離が帯の範囲内かどうか）を高速道路除外と同様にキャッシュ前に適用する。フィルタに現在地座標が必要なため、`ProcessRequestBody`に`lat`/`lon`/`radiusKm`を追加する
- `public/js/`: 結果画面の「探索範囲Xkm圏内」表示を帯の実際の範囲を反映した表記に変更

Phase 3（周辺情報表示）には影響しない。周辺POI検索は目的地決定後の固定半径（500m）の円内検索のままとし、この帯の仕組みは適用しない（目的地探索と周辺情報表示は別の機能であるため）。
