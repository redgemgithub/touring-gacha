# 「この場所に決める」ボタンの撤去と下部シートの再構成

## 背景

結果画面（下部シート折りたたみ時）の「✓ この場所に決める」ボタンについて、実際にアプリを操作した利用者から「何の働きがあるかわからない」という指摘があった。

調査したところ、このボタンはPhase 1の計画段階から意図的に「見た目だけの確定表示」として設計されたものだった（`docs/plans/260828-163014-phase1-店タイプ検索実装.md`に「決定後は視覚的に確定表示にする程度。バックエンドの新規ロジックは不要」と明記）。実装されていた`decided`という状態は、ボタンのラベル文字列（「この場所に決める」⇄「決定済み」）を切り替える以外、一切の効果を持っていなかった（再抽選ボタンの無効化なし、地図表示の変化なし、サーバー側の保存もなし）。

## 検討した選択肢

1. ボタンに実質的な機能（例: 決定後は再抽選ボタンを無効化する）を持たせる
2. 単純に撤去する
3. コードは残しつつ非表示にし、将来何かに使うかもしれない可能性のために温存する

ユーザーの判断: このアプリは「決定」という状態を後続の画面・機能で使う予定が今のところなく、選択肢1のような「操作をロックするだけ」の機能には実質的な意味がない。また、このボタン自体がAI（Claude Code）による自動実装であり、後から必要になった場合に追加するコストは今回撤去してもしなくても変わらないため、非表示で温存する理由（選択肢3）もない。撤去が妥当と判断した。

## 決定: 下部シートを再構成する

単に撤去するだけでなく、「決める」ボタンに本来割り当てようとしていた候補の機能（「別の場所」＝再抽選、「コピー」）を踏まえて、下部シート全体を再構成した。

利用者の観点では、目的地の結果を見て次に取る行動は「この結果で良ければナビ用の情報が欲しい」か「もう一度探し直したい」のどちらかである。前者はすでに情報コピー機能が、後者はすでに再抽選機能が存在しており、決定ボタンを残しても操作の選択肢自体は増えない。むしろ、既存の2つの機能への動線を明確にする方が、この画面の役割がわかりやすくなると判断した。

### 変更前

```
[目的地名・緯度経度・距離]  ← ただの文字表示
[✓ この場所に決める]       ← primary-button。見た目だけで機能なし
[↻ 別の場所] [⧉ ナビ用情報]
[⌃ 周辺のスポットを見る]
```

### 変更後

```
[📍 目的地名・緯度経度・距離]  ← タップ可能なボタン。タップでコピー、長押しで緯度経度強制コピー
[↻ 再抽選]                    ← primary-button。機能は従来の「別の場所」と同一
[⌃ 周辺のスポットを見る]       ← 少し大きく表示
```

- **目的地情報をタップ可能にした**: 展開後の周辺情報一覧にある目的地行（`nearby-destination-item`）が既に持つ「タップでコピー」「長押しで緯度経度を強制コピー」という挙動と完全に同じにし、見た目も同じ`.nearby-item`スタイル（カード風の枠線・タップできることがわかる見た目）に揃えた。これにより「ナビ用情報」ボタンは不要になり撤去した
- **「この場所に決める」を「再抽選」に置き換えた**: 最もよく使う操作（ガチャを引き直す）をメインボタンの位置に配置する
- **「周辺のスポットを見る」を少し大きく表示するようにした**

## モックアップからの乖離

`docs/mockups/main.png`系の`docs/mockups/result-collapsed.png`は「決める／別の場所／ナビ用情報」の3ボタン構成だが、今回の変更によりこれと異なるレイアウトになった。実際の利用を通じて「決める」ボタンに実質的な価値がないことが判明したための、意図的な見直しである。

## 実装

- `public/index.html`: `#sheet-collapsed`内のマークアップを変更（`#candidate-info-button`新設、`#decide-button`/`#copy-open-button`撤去、`#reroll-button`をprimary-buttonに）
- `public/js/views/result.js`: `copyOpenButton`が持っていたコピー・長押しロジックを`candidateInfoButton`に移設。`decideButton`関連のイベント・ラベル切り替え処理を削除
- `public/js/app.js` / `public/js/search.js`: 実質的に無意味だった`decided`状態を削除
- `public/styles.css`: 不要になった`.sheet-title`/`.sheet-coords`/`.sheet-distance`/`.sheet-actions`/`#decide-button`のルールを削除。`.sheet-expand-toggle-large`を新設

詳細な実装ステップ・実行結果は docs/plans/260829-211319-結果画面下部シート再構成.md を参照。
