# .gitignore 初期整備

## Context

touring-gacha は git 初期化直後・コミットなしの状態で、現状 CLAUDE.md / README.md / docs/（要件定義・モックアップ画像）のみが存在する。今後 Node.js + TypeScript + Cloudflare Workers（wrangler）構成で実装を進め、フロントエンドのビルドツール有無やD1/KV導入などは未確定のまま並行して詰めていく。

開発は複数PC（すべて VSCode + Claude Code 拡張導入済み）にまたがって継続する前提のため、最初のコミット前に .gitignore を整備し、
- 機密情報（wrangler のローカルシークレット等）
- ビルド成果物・依存パッケージ・キャッシュ
- OS/エディタ由来の個人環境ファイル

を除外しつつ、他PCで開発を再開するために必要な共有設定（.vscode の共有設定、.dev.vars.example 等のテンプレート類）は残す。

.vscode の扱いはユーザーに確認済み：**共有設定のみコミット**（settings.json / extensions.json 等はコミット、個人依存になりやすい launch.json 等は除外）。

## 実施内容

プロジェクトルートに `.gitignore` を新規作成する。想定スタック（Node.js / npm, TypeScript, Cloudflare Workers + wrangler, 将来的な Vite 導入可能性）を踏まえ、以下をカバーする：

1. **Node.js**: `node_modules/`、npm/yarn/pnpm のデバッグログ
2. **Cloudflare Workers / wrangler**: `.wrangler/`（ローカル実行時のキャッシュ・状態）、`.dev.vars`（ローカルシークレット。`.dev.vars.example` は対象外＝コミットされる）
3. **ビルド成果物**: `dist/`, `build/`, `.output/`, `.vite/`（フロントエンドのビルドツールが未確定なため先回りして含める）
4. **環境変数**: `.env`, `.env.local`, `.env.*.local`（`.env.example` は対象外）
5. **エディタ**:
   - `.vscode/*` を一旦除外した上で `!.vscode/settings.json`, `!.vscode/extensions.json`, `!.vscode/tasks.json` を許可（`launch.json` は個人のデバッグパス等が混じりやすいため除外のまま）
   - `.idea/`（JetBrains系。念のため）
6. **Claude Code**: `.claude/settings.local.json`（個人権限設定）を除外。`.claude/settings.json`（共有設定として今後作る場合）はコミット対象に残す
7. **OS由来ファイル**: `.DS_Store`, `Thumbs.db`, `Desktop.ini`
8. **その他ログ・一時ファイル**: `*.log`, `*.tmp`

## 実行結果

計画通りに `.gitignore` を作成した。node_modules や dist 等、現時点でまだ存在しないディレクトリ・パッケージマネージャも含め、先回りして幅広くカバーする内容とした。
