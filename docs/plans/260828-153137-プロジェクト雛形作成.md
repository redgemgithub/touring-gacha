# プロジェクト雛形作成

## Context

これまでの検討で、インフラ方針（Cloudflare Workers + Workers Static Assets + Workers KV、無料枠運用）とフロントエンド/Workers側の技術選定（バンドラーなし、Workers側はHono採用）が決定した（docs/decisions/260828-infra-cloudflare-kv.md）。Cloudflareアカウント作成・`wrangler login`も完了している。

次のステップとして、実際に `wrangler dev` で動かして確認できる最小限のプロジェクト雛形を作成する。地図ライブラリ選定など後続の検討を実機で試しながら進められるようにすることが目的であり、この時点では機能実装（目的地探索ロジック等）は行わない。

## 実施内容

1. `package.json` を作成
   - dependencies: `hono`
   - devDependencies: `wrangler`, `typescript`, `@cloudflare/workers-types`
   - scripts: `dev`（wrangler dev）, `deploy`（wrangler deploy）, `typecheck`（tsc --noEmit）
2. `tsconfig.json` を作成（Workers向け設定、`@cloudflare/workers-types` を型定義に含める）
3. `wrangler.jsonc` を作成
   - name: `touring-gacha`
   - main: `src/index.ts`
   - assets.directory: `./public`（Workers Static Assetsの配信対象。マッチしないパスはWorkerにフォールバック）
   - KVバインディングは今回は追加しない（実際のキャッシュ実装に着手する段階で `wrangler kv namespace create` を行い、その時に追加する。雛形時点では不要なため）
4. `src/index.ts` を作成（Hono導入の最小疎通確認用に `/api/health` エンドポイントを1つ用意）
5. `public/index.html` を作成（Static Assets配信の疎通確認用の最小限プレースホルダー。本UIはmockupsを見ながら別途実装する）
6. `.dev.vars.example` を作成（現時点でシークレットは無いためプレースホルダーのみ）
7. `README.md`「セットアップ」節・`CLAUDE.md`「コマンド」節に実際のコマンド（`npm install` / `npm run dev` / `npm run deploy` 等）を追記
8. `npm install` を実行し、`wrangler dev` で静的ファイル配信とAPIエンドポイント疎通を確認する（確認後は起動したdevサーバーを停止する）

## 実行結果

計画通りに実施した。

- `package.json`: バージョン番号を手で書かず、`npm install hono` / `npm install -D wrangler typescript @cloudflare/workers-types` を実行してnpmに解決させた（hono ^4.13.5, wrangler ^4.127.0, typescript ^7.0.2, @cloudflare/workers-types ^5.20260828.1）
- `tsconfig.json`, `wrangler.jsonc`, `src/index.ts`（`/api/health`）, `public/index.html`, `.dev.vars.example` を作成
- 確認:
  - `npm run typecheck` → エラーなし
  - `npx wrangler deploy --dry-run --outdir dist` → 成功（バインディングなし、想定通り）
  - `npx wrangler dev` をバックグラウンドで起動し、`/api/health` が `{"status":"ok"}` を返すこと、`/` でStatic Assetsのindex.htmlが配信されることを確認。確認後にプロセスを停止
- `README.md`（現状のステータス・想定スタック・セットアップ節）、`CLAUDE.md`（コマンド節）を実際の内容に更新

KVバインディングは計画通り今回は追加していない（キャッシュ実装時に `wrangler kv namespace create` を行う）。
