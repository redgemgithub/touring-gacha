# 結果画面・下部シート（折りたたみ時）の再構成

## Context

「この場所に決める」ボタンについて、実際に触った利用者から「何の働きがあるかわからない」という指摘があった。調査の結果、このボタンは元々（Phase 1計画時点から）「バックエンドの新規ロジックは不要」な、見た目だけの確定表示として意図的に設計されたものであり、`decided`という状態はボタンのラベル文字列（「この場所に決める」⇄「決定済み」）を切り替える以外、一切何の効果も持たないことがわかった（再抽選ボタンの無効化もしない、地図表示も変わらない、サーバー側の保存もない）。

ユーザーと協議の結果、以下の方針で下部シート（折りたたみ時）を再構成することにした。

## 決定事項（ユーザー確認済み）

現状の構成:
```
[目的地名・緯度経度・距離（ただの文字表示）]
[✓ この場所に決める]  ← primary-button、見た目だけの確定表示。実質的な機能なし
[↻ 別の場所] [⧉ ナビ用情報]
[⌃ 周辺のスポットを見る]
```

新しい構成:
```
[📍 目的地名・緯度経度・距離]  ← タップ可能なボタンに変更
[↻ 再抽選]  ← primary-button。機能は現在の「別の場所」と同一
[⌃ 周辺のスポットを見る]  ← 少し大きく表示
```

- **目的地情報（名称・緯度経度・距離）をタップ可能にする**: タップでコピー（アプリ全体のコピー設定に従う）、長押しで緯度経度を強制コピー。これは展開後の周辺情報一覧にある目的地行（`nearby-destination-item`）が既に持っている「フォーカス済みなら1タップでコピー」という挙動と完全に同じであり、見た目も同じ`.nearby-item`スタイル（カード風・タップできることが分かる見た目）に揃える。ユーザーからの指摘（「底はボタンにしてくれればいいと思うが？周辺情報でボタン表示になってるだろ。あれと同じ」）に対応
- **「この場所に決める」ボタンを「再抽選」に変更**: 見た目上はメインボタン（primary-button）の位置に残るが、機能は現在の「別の場所」ボタンと同一にする
- **「ナビ用情報」ボタンを撤去**: 目的地情報のタップでコピーできるようになるため、同じ機能を重複して持つボタンは不要
- **「周辺のスポットを見る」を少し大きく表示する**

この変更により、`decided`という実質的に無意味だった状態を完全に削除する。

## モックアップからの乖離

`docs/mockups/result-collapsed.png`は「決める／別の場所／ナビ用情報」の3ボタン構成だが、今回の変更によりこれと異なるレイアウトになる。理由は上記の通り、「決める」ボタンに実質的な機能がないことが実際の利用で判明したための見直しであり、意図的な乖離として決定記録に残す。

### `public/js/app.js` / `public/js/search.js`

### `public/styles.css`

## 追記（実装直後のフィードバック対応）: 展開後の目的地行に「現在地からの距離」が欠けていた問題

デプロイ後、ユーザーから「周辺情報に切り替えたとき、目的地の表示内容が折りたたみ時と異なる（現在地からの距離が消えている）。見た目を揃えたことで差が目立つようになった」という指摘があった。

調査したところ、展開後の目的地行（`nearby-destination-item`）はPhase 3から緯度経度のみを表示しており、現在地からの距離は元々表示していなかった。今回の下部シート再構成で折りたたみ時の見た目（名称・緯度経度・現在地からの距離の3行）と展開後の目的地行の見た目（`.nearby-item`スタイル）を揃えたことで、情報量の差が視覚的に目立つようになったための指摘。

ユーザーの意向（周辺POI側は目的地からの距離のままでよく、詳しい距離は不要）に従い、対応範囲を目的地行のみに限定した。

- `public/js/views/result.js`: `buildNearbyItemElement`の`subtitle`が配列も受け付けるよう拡張（複数行の補足テキストに対応）。`renderNearbySection`で、目的地行の`subtitle`に緯度経度に加えて現在地からの距離・方角（`haversineDistanceKm`/`bearingLabel`、折りたたみ時と同じ計算・同じ文言）を追加。周辺POI行（`formatPoiSubtitle`）は変更していない
- Playwrightで、折りたたみ時と展開後の目的地行の表示内容が一致すること、POI行の表示内容が変わっていないことを確認
- `npm run typecheck`エラーなし
